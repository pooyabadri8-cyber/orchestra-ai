# Registry

`agents/*.yaml` — هر فایل شرح یک «کارمند»: نقش، سطح اختیار (L0 قطعی بدون مدل، L1 با مدل ولی فقط پیشنهاد/ایراد)،
نقطهٔ ورود در کد، ورودی‌ها و خروجی‌ها. `templates/*.yaml` — هر فایل یک نوع کار که مدیر می‌تواند برنامه‌ریزی کند:
پارامترها و مراحل با وابستگی‌ها. هنگام بارگذاری اعتبارسنجی می‌شوند: کارمند ناشناخته، چرخه در وابستگی‌ها، نبودن
راستی‌آزما/انطباق/تأیید انسانی پیش از ناشر، یا نقطهٔ ورودی که در کد نیست، بارگذاری را متوقف می‌کند.

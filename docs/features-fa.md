# ادمین هوشمند کانال تلگرام کارگزاری پویان

یک ربات تلگرام که با Claude برای کانال شما پست می‌نویسد، پیش‌نویس را برای **تأیید شما** می‌فرستد و بعد طبق زمان‌بندی در کانال منتشر می‌کند. 

> **حالت خودکار:** در این نسخه `auto_publish: true` است؛ پست‌هایی که از منابع (`sources.yaml`) ساخته می‌شوند بدون تأیید شما زمان‌بندی و در کانال منتشر می‌شوند (بخش «حالت خودکار» پایین). برای برگشتن به حالت قبلی (هر پست با تأیید شما) در `config.yaml` بنویسید `auto_publish: false`.

## چطور کار می‌کند

```
/plan 7  ──►  Claude ایده‌ها را از پایگاه دانش می‌سازد و پیش‌نویس می‌نویسد
                 │
                 ▼
        پیش‌نویس در چت خصوصی شما  ──►  ✅ تأیید  /  🚀 انتشار الان  /  ✏️ ویرایش  /  ❌ حذف
                 │ تأیید
                 ▼
        زمان‌بندی (ساعت‌های config.yaml)  ──►  انتشار خودکار در کانال  ──►  اعلان برای شما
```

- **منبع حقیقت** فقط فایل‌های `knowledge/*.md|txt` است. هر چیزی که آنجا نباشد، agent از خودش نمی‌سازد.
- اگر موضوعی به اطلاعات ناموجود نیاز داشته باشد (مثل کارمزد یا سقف تامین مالی)، agent علامت `[[نیاز به تکمیل: …]]` می‌گذارد و ربات **از انتشار چنین پستی خودداری می‌کند** تا شما تکمیلش کنید.
- قواعد ثابت: بدون تضمین سود، بدون نام بردن رقبا، بدون ادعای اثبات‌نشده، بدون نقل‌قول ساختگی (در `agent/writer.py`).

## راه‌اندازی

1. **ساخت ربات:** در تلگرام به `@BotFather` پیام بدهید، `/newbot` بزنید و توکن را بردارید.
2. **ادمین کردن ربات در کانال:** کانال ← Administrators ← Add Admin ← ربات را انتخاب کنید و فقط دسترسی **Post messages** را روشن بگذارید.
3. **شناسهٔ عددی خودتان:** به `@userinfobot` پیام بدهید.
4. **کلید API:** از console.anthropic.com بسازید.
5. روی سرور:

```bash
cd pouyan-channel-admin
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # و چهار مقدار را پر کنید
python main.py
```

سپس در تلگرام به رباتتان `/start` بدهید. اگر ربات در کانال ادمین نباشد، همان لحظهٔ شروع هشدار می‌دهد.

### اجرای دائمی (systemd)

فایل `/etc/systemd/system/pouyan-admin.service`:

```ini
[Unit]
Description=Pouyan channel admin bot
After=network-online.target

[Service]
WorkingDirectory=/opt/pouyan-channel-admin
ExecStart=/opt/pouyan-channel-admin/.venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now pouyan-admin
journalctl -u pouyan-admin -f
```

> اگر سرور شما در ایران است و دسترسی مستقیم به `api.telegram.org` یا `api.anthropic.com` ندارد، باید ربات را روی سروری با دسترسی بین‌المللی اجرا کنید.

## استفاده از مدل رایگان به‌جای Claude API

کد با هر سرویسی که API سازگار با OpenAI داشته باشد کار می‌کند. فقط `.env` را عوض کنید (چهار خط حالت ۲ در `.env.example`)، بدون تغییر کد:

| سرویس | کلید | نکته |
|---|---|---|
| Google Gemini | aistudio.google.com ← Get API key | مدل‌های Flash در سطح رایگان هستند؛ محدودیت تعداد درخواست دارد و ممکن است داده‌هایتان برای بهبود محصولات گوگل استفاده شود |
| OpenRouter | openrouter.ai/keys | بدون کارت بانکی؛ مدل‌های با پسوند `:free`؛ بدون شارژ حدود ۵۰ درخواست در روز |

اگر `LLM2_*` را هم پر کنید، وقتی ارائه‌دهندهٔ اصلی خطا بدهد یا به سقف برسد، ربات خودکار سراغ پشتیبان می‌رود.

هر `/plan 7` حدود ۸ درخواست مصرف می‌کند (یکی برای تقویم و یکی برای هر پست). کیفیت نوشتن فارسی در مدل‌های رایگان معمولاً پایین‌تر از Claude است؛ پیش‌نویس‌ها را با دقت بیشتری بخوانید. در صورت خطای محدودیت (۴۲۹) ربات خودکار چند بار با تأخیر دوباره تلاش می‌کند.

## بازنویسی و ترجمهٔ محتوا از منابع

منابع را در `sources.yaml` می‌نویسید؛ ربات مطلب‌های جدیدشان را می‌خواند، در صورت نیاز **به فارسی روان ترجمه** و با جمله‌بندی خودش در لحن کانال بازنویسی می‌کند، نام منبع را در پست نمی‌نویسد (`attribution: false`) و در حالت دستی برای تأیید شما می‌فرستد، در حالت خودکار خودش منتشر می‌کند.

| نوع | برای چه |
|---|---|
| `rss` | سایتی که فید دارد (وردپرس: `آدرس‌سایت/feed`) |
| `links` | صفحهٔ اخبار یا خانهٔ سایتی که فید ندارد (مثل Goldman Sachs) |
| `web` | یک مقالهٔ مشخص |
| `telegram` | کانال **عمومی** تلگرام (بدون نیاز به حساب) |
| `telegram_account` | کانال یا **گروه** تلگرام، با حساب خودتان (پایین‌تر) |

**فیلتر موضوعی با اولویت:** در `topics` موضوع‌ها را به ترتیب اولویت می‌نویسید (مثلاً طلا ← نقره ← مس). فقط مطلب‌هایی که واقعاً دربارهٔ آن موضوع‌ها باشند (کلیدواژه در عنوان یا حداقل سه بار در متن) رد می‌شوند و طلا همیشه جلوتر از نقره و مس نوشته می‌شود. کلیدواژهٔ انگلیسی «کلمهٔ کامل» تطبیق می‌خورد (`gold` با `Goldman` اشتباه گرفته نمی‌شود).
**«مهم بودن»** را `focus` تعیین می‌کند: به مدل می‌گوید چه چیزی خبر مهم است و بقیه را `SKIP` کند.

دستورها: `/fetch` (بررسی همهٔ منابع الان)، `/fetch https://…` (بازنویسی یک صفحه)، `/sources`، و `/probe https://site` که فید و لینک‌های خبری یک سایت را پیدا می‌کند تا منبع را درست بنویسید. هر `source_poll_hours` ساعت هم خودکار بررسی می‌شود.

رفتار مهم:
- هر مطلب فقط یک بار پردازش می‌شود (مطلب‌های فیلترشده و قدیمی هم دوباره بررسی نمی‌شوند).
- برای `links` و `web` فایل `robots.txt` سایت رعایت می‌شود. اگر سایتی ربات‌ها را ممنوع کرده باشد، خوانده نمی‌شود.
- متن منبع «داده» حساب می‌شود، نه دستور؛ در حالت دستی هر پست فقط با تأیید شما منتشر می‌شود.
- پست‌ها توصیهٔ خرید/فروش یا پیش‌بینی قیمت از خود ربات نمی‌دهند؛ تحلیل‌های منبع فقط به‌عنوان دیدگاه خود منبع گزارش می‌شود.
- سایت‌هایی که محتوایشان با جاوااسکریپت ساخته می‌شود یا پشت ورود است خوانده نمی‌شوند.

### گروه‌های تلگرام

کانال‌های عمومی با `type: telegram` خوانده می‌شوند. **گروه‌ها** (و کانال‌های خصوصی) را فقط حساب یک عضو می‌تواند بخواند، پس ربات باید با حساب خودتان وارد شود:

1. در my.telegram.org وارد شوید ← API development tools ← یک app بسازید ← `api_id` و `api_hash` را در `.env` بگذارید (`TELEGRAM_API_ID`، `TELEGRAM_API_HASH`).
2. `pip install -r requirements-groups.txt`
3. یک بار `python login_telegram.py` را اجرا کنید؛ شمارهٔ موبایل، کدی که تلگرام می‌فرستد و (اگر دارید) رمز دوم را می‌پرسد.
4. در `sources.yaml` منبعی با `type: telegram_account` و `chat:` بنویسید (نمونه داخل فایل هست) و ربات را ری‌استارت کنید.

هشدارها: فایل `data/tg_account.session` دسترسی کامل به حساب تلگرام شماست؛ به کسی ندهید و در زیپ/گیت نگذارید. فقط گروه‌هایی را بگذارید که عضوشان هستید. ربات اسم اعضای گروه را در پست نمی‌آورد و برای گروه‌های خصوصی فقط «منبع: نام گروه» می‌نویسد (بدون لینک). بررسی گروه‌ها را سبک نگه دارید (چند ساعت یک بار)؛ استفادهٔ خودکار سنگین از حساب شخصی ممکن است تلگرام را حساس کند.

> **ملاحظهٔ حقوقی:** ترجمه و بازنویسی با ذکر منبع جای اجازهٔ صاحب محتوا را نمی‌گیرد، به‌خصوص دربارهٔ تحلیل‌های شرکت‌های بزرگ مثل Goldman Sachs یا پیام‌های گروه‌ها. پیش از تأیید هر پست مطمئن شوید واقعاً بازنویسی است نه رونوشت، و برای عدد و ادعای مالی منبع اصلی را باز کنید و درستی را چک کنید.

## دستورها

| دستور | کار |
|---|---|
| `/plan 7` | تقویم ۷ پستی با پیش‌نویس و زمان پیشنهادی (حداکثر ۱۴) |
| `/draft موضوع \| محور` | یک پیش‌نویس تکی |
| `/auto` | وضعیت حالت خودکار و تعداد پست‌های در صف |
| `/pause` | توقف اضطراری: هیچ پستی منتشر یا خودکار زمان‌بندی نمی‌شود |
| `/resume` | ادامهٔ کار خودکار |
| `/queue` | صف پیش‌نویس‌ها و زمان‌بندی‌ها |
| `/show 5` | نمایش دوبارهٔ پیش‌نویس ۵ |
| `/edit 5 کوتاه‌ترش کن` | ویرایش با Claude |
| `/schedule 5 2026-10-12 10:30` | زمان‌بندی دستی (به وقت تهران، تاریخ میلادی) |
| `/fetch` | بازنویسی مطلب‌های جدید منابع (`sources.yaml`) |
| `/fetch https://…` | بازنویسی یک صفحهٔ مشخص |
| `/sources` | فهرست منابع |
| `/probe https://site` | پیدا کردن فید و لینک‌های خبری یک سایت |
| `/cancel` | لغو حالت ویرایش |

در حالت ویرایش (دکمهٔ ✏️) می‌توانید متن کامل جدید را با `=` در اول پیام بفرستید تا دقیقاً همان جایگزین شود.

## شخصی‌سازی

- **ساعت‌ها، محورها، مدل:** `config.yaml`
- **منابع بیشتر** (متن بروشور، توضیح طرح جدید، پرسش‌های متداول): فایل `.md` یا `.txt` در `knowledge/` بگذارید و ربات را ری‌استارت کنید.
- **اولین کار پیشنهادی:** بخش «هنوز نامشخص» در `knowledge/pouyancrowd.md` را تکمیل کنید (سقف تامین مالی، کارمزد، مدت ارزیابی، فهرست شش وثیقه، عنوان ۸ مرحله). با تکمیل این‌ها، agent می‌تواند قوی‌ترین پست‌ها را بنویسد.

## محدودیت‌های فعلی

- فقط متن (بدون عکس/بنر). تصویر پست‌ها را فعلاً دستی اضافه کنید یا بخواهید در نسخهٔ بعد اضافه شود.
- پاسخ به کامنت‌ها، حذف اسپم و گزارش عملکرد پیاده‌سازی نشده‌اند.
- ربات فقط در چت خصوصی با افراد فهرست `OWNER_IDS` پاسخ می‌دهد.

## عیب‌یابی خطاهای رایج بعد از `/fetch`

- **«You exceeded your current quota» (Gemini) یا «model unavailable» (OpenRouter):** سهمیهٔ رایگان آن مدل پر شده یا نام مدل دیگر معتبر نیست. در `.env` چند مدل را با ویرگول بدهید (`LLM_MODEL=gemini-3.8-flash,gemini-3.6-flash,...`)؛ ربات به‌ترتیب امتحان می‌کند و مدل پر‌شده را چند دقیقه کنار می‌گذارد. برای OpenRouter از `openrouter/free` استفاده کنید (خودش مدل رایگان فعال را انتخاب می‌کند). سهمیهٔ واقعی کلیدتان را در aistudio.google.com ← Rate limits ببینید.
- **`HTTP 403` از یک سایت:** خود سایت ربات‌ها را بسته است. ربات این محدودیت را دور نمی‌زند؛ منبع دیگری (ترجیحاً RSS) جایش بگذارید.
- **«دریافت ناموفق (ConnectTimeout)»:** سایت از شبکهٔ شما جواب نمی‌دهد. اگر سایت فقط بدون VPN باز می‌شود، ربات را هم در همان وضعیت شبکه اجرا کنید.

## گزارش روزانهٔ بازار (`/gozaresh`)

بخشی کاملاً جدا از بقیهٔ ربات (پوشهٔ `agent/gozaresh`، تنظیمات در `gozaresh.yaml`). مدل زبانی و سهمیهٔ رایگان مصرف نمی‌کند، با پست‌ها و منابع کاری ندارد و فقط از صفحهٔ اصلی bourse-trader.ir می‌خواند.

گزارش شامل: شاخص کل (مقدار، تغییر، درصد)، ارزش معاملات خرد، ورود/خروج پول حقیقی در معاملات خرد، و بیشترین ورود و خروج پول حقیقی (سهم و گروه).

- `/gozaresh` — گزارش همین الان
- `/gozaresh 10:30 13:00 18:30` — ساعت‌های ارسال خودکار (هر کس برای خودش؛ ذخیره می‌شود و با ری‌استارت نمی‌پرد)
- `/gozaresh times` — دیدن ساعت‌ها، `/gozaresh off` — خاموش کردن
- گزارش خودکار به چت خصوصی همان فرد می‌آید (نه کانال) و فقط برای OWNER_IDS است.
- روزهای تعطیل (پنجشنبه و جمعه) خودکار ارسال نمی‌شود؛ قابل تغییر در `gozaresh.yaml` (`off_weekdays`).
- اگر ربات سر ساعت روشن نبود و بیش از ۱۵ دقیقه گذشته باشد، آن گزارش قدیمی ارسال نمی‌شود.
- تعداد سهم/گروه هر فهرست: `top_n` در `gozaresh.yaml` (پیش‌فرض ۵).
- اگر سایت تغییر کند و ساختارش خوانده نشود، ربات به‌جای عدد اشتباه پیام خطای واضح می‌دهد.

## قالب ثابت پست‌ها (`post_template.yaml`)

همهٔ پست‌هایی که ربات می‌نویسد (دستی با `/draft`، تقویم `/plan`، بازنویسی منابع و ویرایش با `/edit`) این قالب را دارند:

```
#کارگزاری_پویان
#هشتگ_موضوع

📌  تیتر

🔹بند اول ...
🔹بند دوم ...

☝ فراخوان

منبع: ...        (فقط اگر attribution: true باشد؛ در تنظیم فعلی نوشته نمی‌شود)

➖➖➖
نیاز به راهنمایی دارید؟ ...

لینک‌ها و تماس
```

مدل فقط تیتر، بندها، فراخوان و یک هشتگ موضوع را می‌نویسد؛ هشتگ برند، خط منبع و پاورقی را ربات خودش اضافه می‌کند و در ویرایش به آن‌ها دست نمی‌زند. اگر مدل قالب را کج بنویسد، ربات درستش می‌کند.
برای عوض کردن هشتگ برند، متن پاورقی یا لینک‌ها (اینستاگرام، تلگرام، بله، ربات) فایل `post_template.yaml` را ویرایش و ربات را ری‌استارت کنید. لینکی که خالی بماند در پست نمی‌آید.
پیش‌نویس‌های قدیمیِ ساخته‌شده با قالب قبلی همان‌طور می‌مانند؛ با `/edit شناسه همین‌طور بماند` به قالب جدید تبدیل می‌شوند.

**تبلیغ پویان کراد:** نام و لینک پویان کراد فقط در پست‌های مرتبط (تامین مالی شرکت‌ها، تامین مالی جمعی، معرفی و کارنامهٔ پویان کراد) می‌آید. پست‌های خبری و تحلیلی بازار فراخوانِ عمومی و بی‌لینک دارند و پاورقی فقط مخصوص کارگزاری پویان است (تلفن، اینستاگرام، بله).


## حالت خودکار

با `auto_publish: true` در `config.yaml`:

1. ربات هر `source_poll_hours` ساعت منابع را می‌خواند و پست‌های تازه را می‌نویسد.
2. هر پست از یک بررسی خودکار می‌گذرد (قالب کامل، متن ناتمام، عبارت‌های «بخرید/بفروشید/سود تضمینی»، لینک و آی‌دی در متن، ترجمه‌نشدن، نام منبع، تیتر تکراری).
3. پست سالم **همان لحظه‌ای که آماده شد** منتشر می‌شود و در هیچ صفی نمی‌ماند. بین هر دو پست کانال حداقل ۳۰ دقیقه (`auto_gap_minutes`) فاصله است: اگر پست دیگری ظرف ۳۰ دقیقه منتشر شده یا قرار است منتشر شود، این پست بعد از آن زمان‌بندی می‌شود. پست‌های جدول محتوا سر ساعت خودشان می‌آیند و پست‌های منابع حتی از قبل دورشان جا باز می‌کنند. یک پیام با دکمهٔ «🗑 حذف از کانال» (یا «❌ لغو» اگر چند دقیقهٔ دیگر است) برایتان می‌آید. محدودکردن به یک بازهٔ ساعتی اختیاری است (`auto_from` و `auto_to`).
4. پست مشکوک **منتشر نمی‌شود**؛ مثل قبل با دلیلش و دکمه‌های تأیید/ویرایش/حذف برایتان می‌آید.
5. بعد از انتشار، پیام «منتشر شد» با دکمهٔ «🗑 حذف از کانال» می‌آید (تلگرام فقط تا ۴۸ ساعت اجازهٔ حذف می‌دهد).
6. `auto_max_queue` (پیش‌فرض ۴) سقف تعداد پست در انتظار است تا خبر کهنه منتشر نشود و سهمیهٔ رایگان هدر نرود.
7. اگر ربات بیش از ۲ ساعت خاموش بوده باشد، پست‌های عقب‌افتاده یک‌جا منتشر نمی‌شوند و با فاصله منتشر می‌شوند. هنگام روشن شدن ربات، پست‌هایی که از قبل برای ساعت‌های دور زمان‌بندی شده بودند هم به «همین الان» منتقل می‌شوند.
8. `/pause` همه چیز را فوراً نگه می‌دارد (انتشار و زمان‌بندی)، `/resume` ادامه می‌دهد.

پست‌های `/draft` و `/plan` و `/fetch آدرس` همیشه اول برای تأیید شما می‌آیند. `/gozaresh` مستقل است و تغییری نکرده.

### کانال آرام‌تر: فاصله، سقف و اولویت

- **فاصله:** بررسی منابع هر ۲۰ دقیقه (`source_poll_hours: 0.33`) و حداکثر یک پست در هر بار (`max_new_per_poll: 1`). بین پست منبع و هر پست دیگر کانال حداقل ۲۰ دقیقه فاصله می‌ماند (`auto_gap_minutes: 20`). پست‌های جدول سر ساعت خودشان می‌آیند.
- **سقف:** حداکثر ۹ پست از منابع در روز (`auto_max_per_day`) و حداکثر ۴ پست در انتظار (`auto_max_queue`). پست‌های جدول محتوا جدا حساب می‌شوند.
- **ساعت:** پست‌های منابع فقط بین ۰۸:۳۰ و ۲۳:۰۰ (`auto_from`، `auto_to`).
- **سخت‌گیری:** مدل فقط مطلب «مهم» را می‌نویسد (مصوبه و بخشنامهٔ رسمی، تصمیم یا اظهارنظر مهم مقام‌ها، رویداد قابل‌توجه بازار)؛ لازم نیست «فوق‌العاده» باشد. تکراری، آموزش عمومی، نظر شخصی، تبلیغ، خبر یک نماد و هر چیز دربارهٔ صندوق‌ها رد می‌شود. اگر چند مطلب باشد، اول سنا و بعد Mining.com و بتا سهم نوشته می‌شود (`priority` در `sources.yaml`).
- **سهم‌ها:** پست دربارهٔ سهم یا نماد مشخص ساخته نمی‌شود، به‌جز پست روزانهٔ ساعت ۱۷ دربارهٔ «سهم‌های دارای افزایش سرمایه» (پایین‌تر). کانال «کدال ۷۲۴» غیرفعال شد؛ «سهم روز» جدول به «صنعت روز» (`kind: industry`) تبدیل شد؛ تحلیل آغاز و پایان بازار نام نماد نمی‌آورند. اگر می‌خواهید در پست گزارش بازار هم فهرست تک‌تک سهم‌ها نیاید، در `daily.yaml` بنویسید `report_stocks: false`.
- **افزایش سرمایه (ساعت ۱۷ هر روز):** ربات خبرهای ۳۰ ساعت اخیر را از `capital_sources.yaml` (کدال ۷۲۴، بتا سهم و سنا) می‌خواند، فقط آن‌هایی را که «افزایش سرمایه» دارند نگه می‌دارد و حداکثر ۶ سهم را معرفی می‌کند: درصد یا مبلغ، محل تامین و مرحلهٔ کار، فقط از روی خبر. توصیهٔ خرید، «ارزنده بودن» و پیش‌بینی قیمت ندارد. اگر خبری نباشد آن روز پستی نمی‌آید. ساعت و روز را در `daily.yaml` (مورد `capital`) عوض کنید.
- **خبر صبح:** پست خبری ۸:۳۰ مهم‌ترین رویدادها را به این ترتیب انتخاب می‌کند: جنگ و تنش ایران و آمریکا و هر درگیری مؤثر بر بازار، دلار و ارز، نفت و طلا، توافق و تحریم، تصمیم‌های اقتصادی.
- **لینک‌ها:** پاورقی همهٔ پست‌ها وب‌سایت، تلگرام، لینکدین، اینستاگرام و بله را دارد (`post_template.yaml`). خط لینکدین تا وقتی `url` آن خالی است نمایش داده نمی‌شود.

## عکس پست‌ها

پستی که از یک خبر ساخته می‌شود و خبر عکس خودش را دارد (عکس شاخص مقاله، تصویر فید، عکس پست تلگرام)، می‌تواند با همان عکس منتشر شود و متن پست «کپشن» عکس است.

- `images: true` و `image_ratio: 0.5` در `config.yaml`: حدود نیمی از پست‌های دارای عکس، با عکس می‌آیند (۱ = همه، ۰ = هیچ‌کدام). `image_min_width` عکس‌های کوچک و لوگو را کنار می‌گذارد.
- کپشن عکس حداکثر ۱۰۲۴ کاراکتر است؛ برای این پست‌ها مدل متن کوتاه‌تری می‌نویسد. اگر باز هم بلندتر شد یا عکس مشکل داشت، پست بدون عکس منتشر می‌شود؛ هیچ پستی به‌خاطر عکس از دست نمی‌رود.
- در پیش‌نویس‌هایی که برای شما می‌آیند، عکس جدا نمایش داده می‌شود و دکمهٔ «🖼 حذف عکس» دارد. برای گذاشتن عکس دلخواه، عکس را برای ربات بفرستید با کپشن `/img 5` (۵ = شمارهٔ پست).
- برای منبعی که عکس‌هایش لوگو دارد، در `sources.yaml` بنویسید `images: false` (برای «بتا سهم» گذاشته شده).
- Pillow برای سنجش اندازهٔ عکس لازم است (`requirements.txt`).

### موضوع ممنوع: صندوق‌های سرمایه‌گذاری

ربات دیگر دربارهٔ صندوق‌ها پست نمی‌گذارد. این کار در چهار جا اعمال می‌شود (کلیدهای `exclude_words` و `exclude_symbols` در `config.yaml`):

1. کانال‌های «ترید فاند» و «فاندوستینگ» از `sources.yaml` حذف شدند. مطلبی که کلمهٔ صندوق در عنوانش باشد (یا در متنش سه بار بیاید) اصلاً به مدل داده نمی‌شود، چه در پست‌های منابع و چه در خبر روزانه و تحلیل‌ها. عبارت‌هایی مثل «صندوق بین‌المللی پول» و «صندوق توسعه ملی» صندوق سرمایه‌گذاری حساب نمی‌شوند.
2. ردیف‌های «صندوق ...» از فهرست گروه‌ها در پست گزارش بازار، تحلیل آغاز و پایان بازار و «صنعت روز» حذف می‌شوند. نمادهای ETF که اسمشان «صندوق» ندارد را در `exclude_symbols` بنویسید.
3. به مدل دستور داده شده دربارهٔ صندوق‌ها ننویسد و بخش‌های مربوط به صندوق را از مطلب حذف کند.
4. پستی که با وجود این‌ها تیترش دربارهٔ صندوق باشد یا متنش دو بار یا بیشتر از صندوق بگوید، منتشر نمی‌شود و با دلیل برای شما می‌آید. یک اشارهٔ گذرا (مثل نام صندوق ضامن در طرح‌های پویان کراد) مانعی نیست.

برای برگرداندن صندوق‌ها: `exclude_words: []` و کانال‌های صندوقی را دوباره به `sources.yaml` اضافه کنید. `/gozaresh` که خودتان می‌زنید همان گزارش کامل سایت را نشان می‌دهد و فیلتر نمی‌شود.

**محدودیت:** بررسی خودکار فقط قواعد ظاهری را می‌گیرد و درستی عددها را نمی‌سنجد. در روزهای اول کانال را چک کنید.


## جدول محتوای روزانه (`daily.yaml`)

پست‌های زمان‌دار هر روز، خودکار و بدون تأیید (با همان بررسی ایمنی حالت خودکار):

| ساعت | پست | از کجا |
|---|---|---|
| ۰۸:۳۰ | خبرهای موثر بر بازار (حداکثر ۵ خبر، هر روز) | `news_sources.yaml` |
| ۰۹:۰۰، ۱۰:۳۰، ۱۲:۰۰، ۱۳:۳۰، ۱۵:۰۰ | گزارش بازار (همان `/gozaresh`، بدون مدل و بدون نام منبع) | صفحهٔ bourse-trader |
| ۰۹:۲۰ | تحلیل آغاز بازار | داده‌های بازار + مطالب منابع + خبرها |
| ۱۱:۱۵ | تحلیل نماد یا صنعت روز (از فهرست بیشترین ورود پول؛ یک روز سهم، یک روز گروه؛ تکراری نمی‌شود) | داده‌های بازار |
| ۱۴:۱۵ | تحلیل طلا | مطالب طلا در منابع (فقط اگر مطلبی باشد) |
| ۱۶:۳۰ | تحلیل بعد از بازار | داده‌های بازار + مطالب + خبرها |

- جز خبرها که هر روز می‌آیند، بقیه فقط شنبه تا چهارشنبه هستند (`market_days`).
- ساعت‌ها، روزها و حتی تعداد گزارش‌ها را در `daily.yaml` عوض کنید.
- تحلیل‌ها ۴ دقیقه زودتر نوشته می‌شوند و سر ساعت منتشر می‌شوند. اگر ربات خاموش بود و بیش از ۲۰ دقیقه از ساعت پست گذشت، پست همان نوبت رد می‌شود (دیرکرد ساعت‌ها بعد منتشر نمی‌شود).
- اگر داده نباشد (بازار باز نشده، خبر کافی نیامد، مطلب طلا نبود) چیزی ساخته نمی‌شود و از خودش نمی‌سازد.
- دستورها: `/daily` (جدول امروز و وضعیت)، `/daily شناسه` (ساخت و انتشار دستی)، `/daily شناسه draft` (فقط برای بررسی شما)، `/dailycheck` (تست منابع خبری).
- منابع خبر را در `news_sources.yaml` بگذارید. آدرس‌های اولیه تست نشده‌اند؛ اول `/dailycheck` را بزنید و منبع ❌ را اصلاح یا حذف کنید.
- پست‌های جدول محتوا در سقف `auto_max_queue` حساب نمی‌شوند و پست‌های منابع دیگر ساعت ثابت ندارند (قبلاً `post_times`)؛ فقط دکمهٔ «تأیید» در `/draft` و `/plan` در حالت دستی از آن استفاده می‌کند.
